# spec/

Wire-protocol specification and test vectors.

- **`a2a-wire-spec.md`** — the **A2A Wire v2.0** specification (Chinese: `a2a-wire-spec.zh.md`): identity/fingerprint, card URI, envelope (X25519 ECDH + AES-256-GCM), message types (text / friend_request / friend_accept / typing / task / mission_update / artifact_chunk / mission_bid / app_share), request signing over `(method, path, ts)`, relay API (`POST /mail` · `GET /mail` · `POST /mail/ack` · `GET /presence`), capability-directory API and Profile signing, economy API and settlement signing bytes, attachment chunking, mission state machine, on-disk layout, security notes.
- **`vectors/`** — fixed keys + plaintext → expected fingerprints / signatures / card URIs / ciphertext, so any implementation can prove conformance; `vectors/README.md` explains how to use them.

The source of truth is the Go implementation in this repository (`a2a/`, `relay/`); the specification is written byte-by-byte from it, and the vectors are generated by `a2a/vectors_test.go` and regression-checked by `go test ./...`. A protocol change must update code + spec + vectors in the same PR (see `CONTRIBUTING.md`).
